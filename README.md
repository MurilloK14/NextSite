## 🎯 About The Project

**NextSite** is a complete web experience tailored for offering professional web design and digital presence to businesses and freelancers. Developed with extreme attention to performance, dark aesthetics, and mobile ergonomics.

### ✨ Highlights & Features
- **Modern Visual Engineering:** Glassmorphism, radial lighting, and fluid micro-interactions designed to convey immediate credibility.
- **Mobile-First & Responsiveness:** Meticulously optimized for touch navigation, fast load times, and viewport adaptation.
- **Interactive Portfolio:** Showcase of delivered websites and design cases.
- **Investment Simulator:** Interactive pricing calculator helping prospects make informed decisions.
- **Integrated Conversion Funnel:** Strategic call-to-action buttons connected directly to WhatsApp.

---

## 🛠️ Built With

- **Semantic HTML5:** Clean structure and SEO optimization.
- **Modern CSS3:** CSS Variables, Flexbox, Grid, keyframe animations, and backdrop filters.
- **Vanilla JavaScript:** Smooth navigation, interactive drawers, and pricing simulation.
- **Vercel:** High-availability global deployment and CDN.

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/MurilloK14/NextSite.git
```
2. Navigate to the project directory:
```bash
cd NextSite
```
3. Open `index.html` in your browser or run a local development server like **Live Server**.
